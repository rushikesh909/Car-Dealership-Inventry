# Application Screenshots Guide

Please capture the following actual screenshots from the running application and place them in this folder with the matching filenames:

1. `01-login-page.png`:
   - View of the login screen showing email/password inputs and responsive card styling.
2. `02-register-page.png`:
   - View of the registration screen showing input validation feedback.
3. `03-dashboard-user.png`:
   - View of the dashboard logged in as a standard `USER` role.
   - Show the vehicle grid, search/filter bar, and "Purchase" buttons (with some vehicles in stock and some marked Out of Stock).
4. `04-dashboard-admin.png`:
   - View of the dashboard logged in as an `ADMIN` role.
   - Show the administrative controls: "Add Vehicle" button, "Edit", "Delete", and "Restock" buttons on vehicle cards.
5. `05-search-and-filter.png`:
   - Active search query demonstrating make/model/category filtering and price range sliders or inputs.
6. `06-purchase-success-toast.png`:
   - A vehicle being successfully purchased with the success toast notification visible and inventory count decremented.
7. `07-restock-modal.png`:
   - The Restock modal open with amount input and submission confirmation.
